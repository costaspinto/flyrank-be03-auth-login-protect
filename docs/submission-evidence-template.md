# BE-03 Submission Evidence

`scripts/Submit-BE03.ps1` generates `docs/submission-evidence.md` and `artifacts/pytest-junit.xml`.

Before submitting:
- Check the public GitHub repository and its commit history.
- Confirm source, tests, README, and generated evidence are present.
- Start the API and capture a Swagger `/docs` screenshot showing protected route lock icons.
- If live Supabase credentials are configured, test signup/login/profile/logout with a test account.
- Never include real tokens, passwords, `.env`, or private account data in screenshots.
